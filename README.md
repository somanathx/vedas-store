# Vedas Estd 2015 — E-Commerce Hub

A modern, minimalist e-commerce web application built for a boutique clothing store specializing in ladies' and teen girls' dresses.

## Tech Stack
- **Framework:** React (Vite)
- **Styling:** Tailwind CSS v4
- **State Management:** React Hooks (`useState`, `useEffect`)
- **Storage:** Browser `localStorage` persistence

## Features
- Dynamic product catalog with category filtering (Ladies & Teens).
- Interactive shopping bag with real-time quantity adjustments and pricing calculations.
- Persistent user cart state across browser sessions.
- Clean, light-white minimalist aesthetic tailored for luxury retail.
